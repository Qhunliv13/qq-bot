# 彼岸酱（Qhunliv-bot）

基于 AstrBot 与 NapCat / OneBot 的 QQ bot 插件，包含群聊、共享群记忆、原生工具调用、排队执行、主动观察和后台任务。仓库提供源码、离线测试与运维工具，不包含可直接登录的运行环境或凭据。

## 当前能力与边界

- **共享群记忆**：已记录的群聊按时间合成一条共享上下文，默认最多展示 240 条；保留群、发送者和消息来源。私聊不进入共享群时间线。历史可按关键字检索，不是向量检索；上下文窗口不代表永久记忆容量。群间共享意味着跨群内容可被读取，部署前应确认使用范围。
- **原生工具**：工具目录包含 101 个唯一 schema，覆盖记忆、历史、QQ 操作、文件、虚拟机、任务、技能和委派。目录存在不代表当前账号、上游模型或 NapCat 实现支持全部操作；写权限与目标范围在执行时校验。
- **QQ 申请**：原生入群与好友申请事件单独持久化，不作为空白聊天交给模型。所有者可查看已采集的申请并明确同意／拒绝；审批绑定原生请求与账号，持久防重，未知结果不自动重试。平台受理不等于已入群或已成为好友。当前 NapCat 没有已注册的主动加群、回答入群验证题、主动加好友接口，对应三个工具明确返回能力不可用，不执行替代操作。
- **公开回复**：`reply_now` 默认发送后继续工具回路，可显式使用 `finish=true` 在确认送达且当前工具批次执行完毕后结束，不再额外生成状态回复；不按措辞过滤内容，也不限制多次实质回复。
- **排队执行**：接收的消息排队处理，进行中的工具操作和发送不因后续消息而被抢占；群权限在出队和发送时复核。前台、任务及主动观察复用原生工具回路和执行协调，不保证固定响应时间。
- **主动观察**：持久化调度提供思考机会，不是强制发言。默认机会间隔 600 秒且可调整，轮询间隔 30 秒；只向已观察到的真实会话发起操作，并受群策略和执行忙闲影响。
- **委派 worker**：异步运行只读原生工具子任务，支持查看、排队补充指令和中断；结果回执按会话范围保存。补充指令不打断正在进行的模型请求；进程重启后不自动恢复失去执行者的 worker。
- **后台任务与回执**：任务持久化、执行前认领，失败暂停；未确认结果的认领不自动重试。当前任务上限 50 个、最短间隔 30 秒，约每 25 秒检查到期任务并等待执行锁；不是准点交付保证。QQ 消息发送依赖平台消息 ID 回执，不能以模型文本、HTTP 成功或服务存活替代送达证据。

模型和工具仍受各自请求超时、可配置回合/整轮预算、平台权限与外部服务可用性约束；不承诺无限执行、全部工具可用或测试覆盖真实部署的所有路径。

## 目录

| 路径 | 用途 |
|---|---|
| [`plugin/`](plugin/) | AstrBot 插件与原生工具、记忆、排队、任务和回执实现 |
| [`tests/`](tests/) | 离线单元、契约与集成适配测试 |
| [`tools/`](tools/) | 探针、策略管理、发布检查与受控应用工具；各文件的参数和副作用需单独确认 |
| [`tools/ops/`](tools/ops/README_HER_OPS.md) | 按原用途保留的运维与补丁脚本索引，不是当前部署步骤 |
| [`local-her/`](local-her/README.md) | 本机调试目录说明与整理档案；不随仓库分发本机运行数据 |
| [`reports/`](reports/) | 探针、审计、部署结果等历史报告 |

`tools/*_probe.py` 等探针的联网、读取和发送范围并不相同，执行前先读脚本；不把所有探针统一视为只读。`tools/validate_release.py` 检查发布文件，`tools/release_apply.py` 提供校验、备份、应用与回滚入口，使用前仍需核对目标、权限及影响。

## 本地检查与配置

```bash
python -m pytest tests -q
python -m compileall -q plugin
```

这些命令验证本地源码，不代表实际 QQ 登录、模型请求或生产部署已通过。运行需要自行配置 AstrBot、NapCat / OneBot、模型提供方、数据目录与访问权限。`HIGAN_ROOT` 指定插件数据根目录；部分模块仍有默认绝对路径，迁移前须逐项核对。

密钥、密码和令牌仅从私有运行配置或相应环境变量提供。不要提交运行数据库、聊天档案、图片附件、工具观察文件、会话资料或 Dashboard / 上游凭据；非秘密路径与账号标识也应在部署前复核。

## 版本与档案

当前源码以所检出的 Git 提交及其 tag 为准。根目录的 `RELEASE_*`、`DEPLOYED_*`、审计说明，以及 `reports/`、`local-her/` 中的记录属于发布或运维档案，其日期和结论不代表当前版本号、当前部署事实或功能契约。阅读档案时应对照当前源码、配置与现场证据，不据旧记录直接执行补丁。

发布与运维档案保留原始记录，用于追溯，不替代当前源码与配置。
