# 配置与调参

配置分两层：**实例配置**（随部署而变，走 AstrBot 配置面板）与
**项目级调参**（通用工程默认值，写在 `main.py` 顶部）。

---

## 一、实例配置

落盘位置：`data/config/astrbot_plugin_group_ai_config.json`
（由插件目录里的 `_conf_schema.json` 生成，可在 AstrBot 的插件配置面板里编辑）。

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `owner_ids` | 列表 | 空 | 管理员（"主人"）QQ。**留空 = 不区分身份**，所有发言人都按普通群友对待 |
| `bot_name` | 字符串 | 空 | 机器人在提示词里的自称；留空用 `prompts.DEFAULT_BOT_NAME` |
| `persona` | 文本 | 空 | 自定义人设正文；留空用 `prompts.DEFAULT_PERSONA`（通用默认人设） |
| `persona_file` | 字符串 | 空 | 人设文件路径（相对 AstrBot 工作目录）；**存在则优先于 `persona`** |
| `target_groups` | 列表 | 空 | 只在哪些群工作；**留空 = 所有群** |
| `member_watch_groups` | 列表 | 空 | 监听哪些群的成员变动；**留空 = 不监听** |
| `onebot_base` | 字符串 | `http://127.0.0.1:3000` | OneBot 的 HTTP 接口地址 |
| `web_enabled` | 布尔 | `true` | 是否允许联网查询（搜索 / 打开网页 / 搜图）。关掉后提示词不再引导模型联网 |

**列表类字段的写法**很宽松：列表 `["123","456"]`、单个数字 `123`、
分隔字符串 `"123, 456、789 012"`（中英文逗号/顿号/空格/分号/竖线/斜杠都当分隔符）都可以。
非法项会被丢弃而**不会让插件启动失败**。

### 关于 `persona` 与 `persona_file`

- 两者都留空 → 使用**通用默认人设**（一个友善、话不多的群成员口吻，内置语气红线）。
- 想用自定义角色：短的就填 `persona`，长的建议写文件并用 `persona_file` 指过去。
- 默认人设里刻意写了**语气红线**（不刻薄、不抬杠、不贬低、被指出要认错）——
  这是通用要求，与具体角色无关，建议自定义人设时保留。

### 关于 `member_watch_groups`

监听会**周期性拉取群成员名单**（间隔见 `MEMBER_WATCH_INTERVAL`）。
大群（上千人）单次名单可达 MB 级，所以：

- 只填**确实需要感知加群/退群**的群；
- 与 `target_groups` **分开配置** —— 监听只是读名单，不应该因此限制机器人在别的群也能聊天。

## 二、项目级调参（`main.py` 顶部常量）

### 回复频率

| 常量 | 默认 | 说明 |
|---|---|---|
| `MIN_REPLY_INTERVAL` | 30 | 非 @ 回复的最小间隔（秒）。**调小更活跃、调大更安静** |
| `MIN_WOKEN_INTERVAL` | 5 | 被 @ 时的最小间隔（秒） |
| `MAX_REPLY_PER_MIN` | 3 | 非 @ 每分钟上限 |
| `MAX_WOKEN_PER_MIN` | 6 | 被 @ 时每分钟上限 |

> 这四项决定"话痨程度"。如果觉得太安静，先降 `MIN_REPLY_INTERVAL`；
> 如果觉得吵，先升它并降 `MAX_REPLY_PER_MIN`。

### 图片与视觉调用

| 常量 | 默认 | 说明 |
|---|---|---|
| `REVIEW_IMAGE_MAX_SIDE` | 512 | 发给模型前把图压到多少像素。**决定快慢的关键项** |
| `REVIEW_TIMEOUT` | 25 | 单次视觉调用（挑图/描述）超时（秒），超时则跳过该步 |
| `CHAT_TIMEOUT` | 45 | 单次生成回复超时（秒），超时则本次不回 |
| `GIF_MAX_FRAMES` | 4 | 动图抽几帧 |
| `MAX_CANDIDATES` | 5 | 挑表情包时给模型看几张候选 |
| `MAX_REMEMBER_IMAGES` | 5 | 每群保留几张"最近图" |
| `MAX_IMAGES_PER_CALL` | 3 | 单次送给模型的图片数量上限 |

> 视觉调用慢就先降 `REVIEW_IMAGE_MAX_SIDE`（例如 384），再考虑降 `MAX_CANDIDATES`。

### 表情包库

| 常量 | 默认 | 说明 |
|---|---|---|
| `MAX_STICKERS` | 300 | 库上限，超限按"最久未用"淘汰 |
| `MAX_STICKER_BYTES` | 4 MiB | 单张体积上限（**字节**），超过不收录 |

存储位置：`data/stickers/`（图片文件 + `manifest.json` 索引）。
把图片直接丢进该目录，插件启动时会自动登记并补描述。

### 联网

| 常量 | 默认 | 说明 |
|---|---|---|
| `SEARCH_TIMEOUT` | 20 | 搜索/抓网页超时（秒） |
| `SEARCH_TOP_N` | 5 | 搜索结果取几条 |
| `PAGE_FETCH_TOP` | 2 | **打开几个网页读正文**（0 = 只给摘要） |
| `PAGE_FETCH_TRY` | 4 | 最多尝试打开几个（部分站点反爬 403，多试几个才有成功的） |
| `PAGE_TEXT_LIMIT` | 2500 | 单页正文最多取多少字符 |
| `MAX_DOWNLOAD_BYTES` | 5 MB | 下载图片的体积上限 |

### 群成员监听

| 常量 | 默认 | 说明 |
|---|---|---|
| `MEMBER_WATCH_INTERVAL` | 60 | 轮询名单间隔（秒）。名单拉取有网络开销，别设太小 |

### 身份与唤醒

| 项 | 来源 | 说明 |
|---|---|---|
| 管理员 QQ | **实例配置** `owner_ids` | 不在代码里写死；留空即不区分身份 |
| 机器人自称 | **实例配置** `bot_name` | 用于提示词与唤醒词匹配 |
| `SILENT_MARKERS` | 代码常量 | 模型表示"这次不接话"的若干写法（大小写、中英文括号变体） |

## 三、改配置后的验证

1. 静态检查（不依赖 `python -m pyflakes` 入口）：
   ```bash
   python tools/lint_pyflakes.py astrbot_plugin_group_ai
   ```
2. 重启 AstrBot，看日志里插件是否正常加载（会打印表情包库数量与人设字数）。
3. 群里发一条消息，确认：
   - 日志出现"收到群 … 消息"；
   - 被 @ 时出现"被 @ 直接回复"；
   - 未被 @ 时可能出现"模型选择不接话"（这是正常的判断结果）。
4. 若改了 `member_watch_groups`，确认日志出现"成员基线：N 人"
   （**首次只建基线，不会刷"全员加入"**）。
